Language Matcher API

The routing service for Language Matcher. The interface is deployed separately — this host only answers JSON.

  • Get/api/health
  • Get/api/meta
  • Get/api/leads
  • Get/api/bds
  • Get/api/analytics/summary
  • Post/api/assignments/run

Browser calls are restricted to the origins listed in CORS_ORIGIN. There is no authentication: this is a demo service.
